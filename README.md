# Muhtâr li'l-Fetvâ · Giray Akademi

Abdullah b. Mahmûd el-Mevsılî'nin (ö. 683/1284) *el-Muhtâr li'l-Fetvâ* metni için çalışma programı: 56 kitap, 3409 ibare, harekeli Arapça metin, Türkçe tercüme ve dipnotlar, isteğe bağlı açılan *el-İhtiyâr li-Ta'lîli'l-Muhtâr* şerhi, her bölümün sonunda test (775 soru).

Adres: https://alpkiraym.github.io/muhtar_lil_fetva/

## Kaynaklar

- Arapça metin: el-Mevsılî, *el-Muhtâr li'l-Fetvâ* ve *el-İhtiyâr li-Ta'lîli'l-Muhtâr* (harekeli metin).
- Türkçe tercüme ve dipnotlar: Prof. Dr. Orhan Çeker, *Muhtâr'ın Anahtarı*. "Ek tercüme" etiketli ibarelerin tercümeleri bu eserden değildir.
